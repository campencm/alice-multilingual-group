# alice-multilingual-group

Member Names: Kendal Smith, Cj Campen, Lexie Hayes

Languages Analysed: English, Spanish, Finnish, Italian

Model names: en_core_web_sm, es_core_news_sm, it_core_news_sm, fi_core_news_sm

Reproduction Instructions: 

1. open the repo in RStudio
2. install Python and required libraries (see requirements.txt)
3. download spaCy language models in Model names (above)
4. download "Alice's Adventure's in Wonderland" in each required language, 
naming them in this format: "language_alice.txt", then place them into the data
folder
5. open HW7_alice.qmd and run all cells from top to bottom
